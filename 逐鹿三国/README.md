# 逐鹿三国（第一阶段：网页原型）

三国回合制势力争霸。剧本是建安五年（200 年）官渡前夜：选一位君主，每季给每位武将下一道命令，先占 15 座城（共 22 座）就赢。

## 怎么玩

下载后双击 `index.html`，用浏览器打开就能玩，不用安装任何东西。存档自动保存在浏览器里。

书法字体从谷歌字体加载。加载不到时会自动换成电脑自带的楷体、宋体，不影响玩。

## 文件分工

| 文件 | 管什么 | 什么时候改它 |
| --- | --- | --- |
| `data.js` | 剧本数据：城池、道路、武将、开局兵力钱粮、各势力好战程度 | 调数值、加城、加武将 |
| `rules.js` | 游戏规则：指令效果、战斗结算、收入、事件、胜负 | 改玩法 |
| `ai.js` | 电脑势力怎么决策，以及「军师进言」 | 改电脑的打法 |
| `ui.js` | 界面：地图、侧栏、战斗动画、战报 | 改界面和交互 |
| `portraits.js` | 武将立绘：有画好的就用 `立绘/` 里的图片（目前 46 人都有）；新加的武将没有图时，用 SVG 现画一幅绣像风格的代替，长相写在 `LOOKS` 表里 | 加了新立绘后把武将 id 加进 `PAINTED` |
| `立绘/` | 立绘图片：`<id>-full.jpg` 整张（720×1080，详情页和剧情用）、`<id>.jpg` 半身像（320×400）、`<id>-head.jpg` 头像（160×160）、`faces.js` 脸的位置；`原图/` 是单人立绘原画（缩到 768×1152 保存） | 换立绘 |
| `lore.js` | 武将列传：字、籍贯、称号、出处，只给“武将”详情页显示用 | 改人物介绍 |
| `story.js` | 剧情台词：四家开局、子龙来投、小霸王陨落、河北生变、孙刘联盟、三顾茅庐、名将归附；有的带选项（只是演出，不改数值） | 改台词、加剧情 |
| `scene.js` | 剧情的演出：水墨山水背景（代码现画）、立绘登场、打字机对白、选项、自动 / 跳过 / 回看 | 改剧情画面 |
| `siege3d.js` | 3D 攻城动画：玩家出征时播 9 秒左右（行军、单挑、箭雨火计、云梯登城、冲车撞门、破门入城换旗或败退），按这一仗的真实数据演，可跳过。做法参照推箱子 3D：物理材质、环境光反射、胶片色调映射，贴图全部用画布现画（青砖、筒瓦、木纹、门钉、水面、旗帜、匾额）。第一次打开出征表单时才加载 `vendor/three.min.js`；没有 WebGL 或系统要求减少动画时自动跳过 | 改攻城画面 |
| `kit3d.js` | 3D 共用工具箱：加载 three.js、画布贴图（砖、瓦、木、水、旗、匾）、物理材质、天空与光照、屋顶/城楼等积木，攻城动画和沙盘共用 | 改 3D 的材质、光照 |
| `sandbox3d.js` | 3D 沙盘：棋盘右上角点「沙盘」切换。山脉、黄河长江、海岸按舆图数据起伏成地形，城池是小城楼、插本家旗帜，势力范围淡淡染在地上，道路虚线连城；城名牌照旧可点。拖动平移、右键或双指旋转、滚轮或双指缩放，⟲⟳ 转向、俯视/斜视、全图。选择会记住；被主菜单、武将详情盖住时停画省电 | 改沙盘画面 |
| `vendor/` | Three.js r160（MIT 许可，见 `THREE-LICENSE.txt`），放在本地，双击打开也能离线用 | 一般不用动 |
| `style.css` | 样式和配色（颜色都在文件开头的变量里） | 改外观 |

规则和界面是分开的：`rules.js`、`ai.js` 不碰界面，以后搬进 Cocos 时可以原样复用。

## 调平衡用的小工具（在 tools 文件夹）

需要 Node.js 18 或更新版本：

```
node tools/sim.cjs 40 60
```

- `sim.cjs`：四家全交给电脑，跑 40 局、每局最多 60 季，看谁领先。改完数值先跑它。
- `calib.cjs`：检查出征时显示的「胜算」和实际攻城成功率对不对得上。
- `tour.cjs`：用无界面的 Edge 自动试玩一遍并截图，检查有没有报错、手机上会不会撑破屏幕。（这个脚本在网址后面加了 `#nostory`，跳过剧情对话。）
- `crop_art.py`（Python，需要 Pillow）：把 `立绘/原图/<id>.jpg` 做成整张、半身像、头像三种尺寸，并写出 `立绘/faces.js`。换了某人的原图，先核对脚本里他的脸的位置。

## 介绍视频

成片在 `视频/逐鹿三国-介绍.mp4`（1080p，约 1 分 28 秒），封面是 `视频/封面.jpg`。内容：择主、剧情对白、舆图与 3D 沙盘、出征、3D 攻城、军师议事、武将详情与召见、四十六人立绘长卷。上一版只录玩法、没有立绘和 3D，留在 `视频/逐鹿三国-玩法实录（旧版界面）.mp4`。

做法：真实玩一局，逐帧录下来再剪。

1. `tools/plan-video.cjs`：先在 Node 里排练，挑一个好看的开局种子（首季关羽攻寿春，有单挑和火计，一战而下）。
2. `tools/record-video.cjs`：无界面 Chromium 打开游戏，固定种子，按顺序真实点击；页面里画一个可见的鼠标指针。用假时钟一帧一帧地走（每帧 1/30 秒），每帧截一张图，CSS 动画、打字机、3D 沙盘和攻城动画都按这个时钟走，所以机器再慢也不掉帧。没有显卡时 3D 画面一帧要几秒，整段录完约一小时。
3. `tools/video_assets.py`、`tools/video_captions.json`：片头、片尾、字幕条、群英立绘长卷。字幕文字都在 json 里改。字体用 Google Fonts 的马善政和思源黑体。
4. `tools/video_music.py`：用代码合成的配乐（五声音阶拨弦 + 战鼓），没有版权素材。
5. `tools/make_video.py`：按分镜取片段、变速、叠字幕、交叉淡化，合成配乐。

```
node tools/record-video.cjs <playwright 路径> <工作目录> [chromium 路径]
python tools/video_assets.py <工作目录>/assets 马善政.ttf 思源黑体粗.ttf 思源黑体.ttf
python tools/make_video.py <工作目录> 视频/逐鹿三国-介绍.mp4
```

需要的工具：Node.js 和 playwright、Python 的 numpy 和 Pillow、ffmpeg。

## 已知情况

- 纯电脑对局里孙吴偏强（40 局约赢 22 局），原因是江东背靠大海、旁边有荆州可取。对玩家影响不大，后面可以继续调。
- 开局一年内电脑不会主动打玩家；玩家先打了谁，谁就会还击。
